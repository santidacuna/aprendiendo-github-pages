# Mi primer sitio con GitHub Pages

Este sitio fue publicado directamente desde un repositorio de GitHub.

## ¿Qué estoy practicando?

Estoy aprendiendo cómo GitHub puede utilizarse no solamente para almacenar archivos y controlar versiones, sino también para publicar contenido web.

## Cómo funciona

El contenido de esta página está escrito en Markdown dentro del archivo `index.md`.

Cada modificación que se incorpora a la rama `main` puede generar una nueva versión del sitio publicado.
