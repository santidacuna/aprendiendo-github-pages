# Aprendiendo GitHub Pages

Este repositorio fue creado para experimentar con la publicación de contenido mediante GitHub Pages.

## Objetivo

Comprender cómo los archivos de un repositorio pueden convertirse en un sitio web accesible desde Internet.

## Contenidos

- Publicación desde una rama.
- Uso de Markdown como contenido web.
- Configuración básica de GitHub Pages.
- Actualización del sitio mediante commits.
